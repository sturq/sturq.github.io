asf-autoidle

idle every owned game, on rotation

an archisteamfarm plugin that auto-idles every game in a bot's library by rotating them in batches of 32 — steam's per-bot idle cap.

configurable rotation interval, picks up where it left off across restarts, hot-reloadable. drop it into asf's plugins/ folder.
