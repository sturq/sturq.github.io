runava

runelite for android, with touch controls

runelite for android with touch-friendly controls. built on top of amethyst / pojavlauncher's caciocavallo awt runtime so the official runelite.jar runs unmodified.

runelite.jar is fetched from upstream releases on first launch. supports the full runelite plugin api and custom on-screen control mappings.
